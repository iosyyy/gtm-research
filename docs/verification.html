当前环境为 macOS 上的 DeepSeek Harness 0.2.1-rc.5。插件、教程和测试源码均提供在同一仓库，方便复查和修改。

已检查的部分

  • 两套技能目录：GTM Agents 244 项、Zime 71 项，全部具有中文用途及来源路径。当前仅开放两套官方来源。
  • 19 项代码检查通过，涵盖会话接口、工作区身份、选择恢复、模板表单和技能选择一致性。
  • 共用 Host 服务的状态、模板更新和真实文件检查，包含目录越界及错误签名拒绝。
  • 真实按钮已完成完整研究：系统默认浏览器 Crest，可见窗口采集 10 个主题正文和 112 条评论；Agent 通过 web_research_manage 更新进度并返回 PDF / Excel。
  • 本次插件产物：PDF 767,770 字节、Excel 41,491 字节，经 Host 文件检查后标记完成。另有此前完整对话案例，产出 PDF 和 11 个工作表的 Excel。

使用前要知道

  • 当前内置浏览器没有模型控制工具，仅打开网页不等于可以自动研究。自动模式会尝试后改用可见浏览器；指定引擎不可用时提示改选。
  • agent-chrome 是可选兼容 CLI，需要本机已有且能够连接；未指定确切来源时不自动安装同名项目。
  • 已有依赖的电脑可验证复用流程，不能冒充全新机器下载测试。
  • PDF 样式模板是排版参考，不能保证像素级复刻。Excel 公式和结构需要按具体模板验证。
  • 开始研究留在工作台；独立的“查看执行过程”同页展示真实会话，“打开执行对话”进入完整会话。AI 动态计划和更完整的 CRM 流程仍在后续需求中。
  • 这份静态网站不会连接访客的本机账号、浏览器或文件。下载源码后在自己的 Harness 安装和运行。
